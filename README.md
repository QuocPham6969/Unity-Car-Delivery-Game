# Unity Car Delivery Game

## Overview
Unity Car Delivery Game is a 2D driving game developed in Unity where the player controls a car, collects packages, and delivers them to customers while navigating around traffic and obstacles.

The project focuses on vehicle movement, delivery gameplay, AI-controlled cars, collision interactions, UI feedback, and environmental systems such as a day/night cycle.

## Project Type
Individual Unity game development project.

## My Contributions
In this project, I was responsible for:
- Player car movement and steering
- Package pickup and delivery system
- AI-controlled vehicle waypoint movement
- Vehicle collision and knockback behavior
- Camera follow system
- Countdown timer and game UI
- Player feedback and announcement messages
- Day and night lighting cycle
- Gameplay debugging and iteration
